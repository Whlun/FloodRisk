# 韶山水环境设施管理系统

## 业务与功能

### 定位

由「韶山水环境一张图」原型中的**设施管理**模块拆分而成的独立原型项目，名称：**韶山水环境设施管理系统**。

### 功能范围（与原一张图设施管理一致）

| 模块 | 说明 |
|------|------|
| 排水管网 - 排水管点 | 管点台账、检查井/雨水口扩展字段、详情与编辑、字段管理；**详情弹窗**仅 **「基本信息」**（分「管点基础信息」及检查井/雨水口扩展卡片），**不含实时监测** |
| 排水管网 - 排水管线 | 管线台账、起点/终点管点关联（新增/编辑表单中为 **可搜索下拉**，选项与 **排水管点台账 `pipeNodeData`** 同源，支持按编号/类型/道路筛选；起点与终点不可相同）、详情与字段管理 |
| 排水管网 - 管线档案信息 | 以**管线工程项目维度**管理资料：主列表风格与项目档案一致，具备 **导出Excel / 导入 / 字段管理 / 新增** 工具栏能力；支持按 **项目类型、项目名称、项目编号** 查询，字段口径为 **管线工程名称、工程编号、工程类型、所属区划、建设范围、规划工期、工程描述**。操作列提供 **详情 / 编辑**，并支持在编辑弹窗内删除；项目资料入口位于 **项目资料** 列（资料数徽标+资料按钮）。新增/编辑弹窗为 **基本信息 / 项目资料** 双 Tab，项目资料支持快速上传（原型写元数据）与删除；详情弹窗同样提供 **基本信息 / 项目资料** 双 Tab。资料列表支持**在线查阅、下载、打印**原型流程（预览为占位，不接真实后端文件流）。 |

### 列表 / 详情 / 编辑 / 新增（与「排水管点」一致）

五类设施（管点、管线、泵站、排口、污水厂）统一为：

- **详情**：列表「详情」→ **居中弹窗**展示只读详情（**无底部按钮**，关闭通过弹窗**右上角**关闭图标或遮罩/ESC（`onCancel`））。为避免整窗出现上下滚动，`detailModalStyles` 采用**外层禁滚 + 内容区紧凑排版**（监测页内部卡片按区域自滚），其中左侧设备元数据卡片保留独立纵向滚动。**泵站、排口、污水厂**详情因含 **实时监测** 宽表，弹窗宽度为 **`min(1200px, 96vw)`**；**排水管点、管线**及其余详情弹窗宽度为 **800px**。管线为分 Tab 的 `Descriptions`；泵站/排口/污水厂为湘潭风格多 Tab 详情，标题由弹窗 `title` 承载。
- **泵站 / 排口 / 污水厂 · 实时监测**（`pipe-node-monitoring.tsx`，`scene` 区分场景；占位时序/末值/通道态与 **`facility-realtime-snapshot.ts`** 同源，供综合态势地图 POI 物联提示板复用）：**「关联物联设备」** 按钮打开弹窗，从物联平台设备清单中 **多选绑定**（可增删、随时修改）；弹窗交互 **对齐生态整治「河湖长制 · 河长责任区域」选择责任段**：**`Select` `mode="multiple"`** + **`showSearch`** + **`maxTagCount="responsive"`**，下方 **`Card`「已选物联设备」** 内 **`Table`** 列出已选（空态文案「暂未选择设备，请在上方搜索并多选」），行内 **移除** 与下拉选项联动；未关联时展示空态与说明，关联后仅展示已选设备卡片。同一套 **设备横滑卡片** + **设备信息**（左侧物联网元数据 + 右侧压力/流量/液位等指标大卡）+ **按日期** 三曲线或 **按范围** 单序列；时间维度切换控件采用 **`Segmented`（按日期 / 按范围）**，视觉与综合态势右栏切换器口径一致；时间筛选控件口径为：**按日期使用单日 `DatePicker`，按范围使用 `RangePicker`**。台账可选字段 **`iotLinkedDeviceKeys`**（`string[]`）用于原型初始勾选，缺省为全选示例设备。示例池中含 **2 条无监测数据的空占位设备**（`key` `6`、`7`），选中后指标为「—」、曲线区为 **Empty**；其余为 **物联网平台接口占位**，对接后替换。**设备横滑卡片**：**选中态**使用 **主色描边 + 外圈光晕 + 轻微上移**，标题与闪电图标同色加深；CSS 中 `.active` 规则置于各 `tone-*` 之后，避免档位边框色盖住选中描边。边框/底色按当前展示的监测项集合取 **最高档**——**正常**为绿、**任一告警通道**在聚合时按 **红色档** 计（与指标大卡将告警数值统一标红的口径一致，避免出现「大卡已红、卡片仍为橙框」）；业务上四级告警（红橙黄蓝）在对接后若大卡分区着色，横滑卡应改为按接口档位聚合。**仅当全部监测项离线**（或设备无数据）时为 **离线灰** 且 WiFi 灰，其余 WiFi 绿。**指标大卡**在同一行内按当前选中设备的监测项档位 **从左到右** 排序：**红→橙→黄→蓝→绿→灰**（同档保持原有监测项顺序）；**电量**卡固定排在监测项之后，**可点击选中**（与其它大卡一致有高亮态）；选中后下方 **曲线 / 柱状 / 表格** 与其它监测项同源交互，占位数据围绕卡片当前电量百分比生成 **0～100%** 时序（末点对齐卡片读数，对接时序库后替换）。**单位**仅在卡片底部单位区展示一次，数值区不重复拼接单位。
- **泵站 / 排口 / 污水厂 · 视频监控**（`facility-video-monitoring.tsx`）：与实时监测 **相同的关联逻辑** — **「关联视频设备」** 弹窗多选视频通道（可增删、随时修改）；主页面采用 **左树右 4 宫格**：左侧为可搜索摄像头树（支持按名称/通道编码过滤，勾选联动右侧，**最多勾选 4 路**），右侧固定 2×2 预览窗口，按勾选结果展示视频占位；未勾选窗口显示「未选择摄像头」。页面整体不做外层纵向滚动，仅左侧树区内部可滚动。台账可选字段 **`iotLinkedVideoKeys`**（`string[]`，与通道 `key` 如 `v1`…`v7` 对应），缺省为全选示例通道。示例池中 **2 路为无画面空占位**（`v6`、`v7`），预览文案区分「暂无画面」；其余为 **视频云平台 / RTSP/HLS** 对接前占位。
- **编辑**：列表「编辑」→ 宽度 **800px** 的弹窗（与生态整治项目管理新增/编辑一致），内嵌 **可提交表单**（`Form` + **`Divider titlePlacement="start"`** 分节标题），保存时校验并更新本地台账；弹窗底部为 **删除 / 取消 / 保存**（删除仅在编辑态出现）。弹窗 **标题与底部按钮固定**，仅中间 **表单/详情内容区**（`Modal` 的 `body`）在内容过长时 **上下滚动**（`maxHeight: calc(100vh - 240px)` + `overflow-y: auto`）。
- **新增**：卡片右上角 **新增**（`PlusOutlined`）→ 独立弹窗，宽度 **800px**，底部 **取消 / 保存**，保存后插入台账并生成新标识码（前缀与业务一致，如 `L` / `PS` / `OF` / `WWTP` 等）。滚动规则与编辑弹窗一致（中间滚动、头尾固定）。
- **编辑弹窗内「详情 / 编辑」切换**：非编辑态展示只读详情，底部仅「进入编辑」；关闭弹窗通过**右上角**关闭图标或遮罩/ESC，与详情弹窗一致（避免与底部「关闭」重复）。

### 列表表格与字段管理（与「排水管点」一致）
