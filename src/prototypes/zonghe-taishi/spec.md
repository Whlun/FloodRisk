# 综合态势

## 业务与功能

### 1.1 核心目标

「综合态势」为韶山高新区水环境综合整治一张图的**大屏总览入口**，在一屏内整合管网与水利设施指标、动态感知摘要、应急资源概况、地理底图上的**设施管理同源台账点位**（泵站、排口、污水厂）与**右侧水质与报警分析看板**（示例数据）。目标用户为指挥中心值班与管理决策人员，需快速把握全局态势并在地图上打开与 **韶山水环境设施管理系统** 列表 **详情** 一致的弹窗内容。

### 1.3 交互要点

- **报警铺满查询生效（P0）**：筛选行提供并排 **「查询 / 重置」** 按钮（`Space` 组合，视觉与设施管理检索按钮组一致）；点击 **「查询」** 后按当前筛选条件（区域、监测点类型、监测项类型、报警级别、名称关键字、日期范围）过滤卡片与列表同源数据；点击 **「重置」** 清空筛选并恢复全量结果。
- **日历单日联动查询（P0）**：分析看板中的 **「排口水质报警日历」** 日期格支持键鼠点击；触发后页面切换至报警 **overlay** 并自动按该日期执行单日查询（`RangePicker` 同步为起止同一天）。后续手动修改筛选条件与点击 **「查询/重置」** 保持原行为不变。
- **日历网格铺满（P1）**：分析看板三等分布局下，日历日期区采用固定 **7 列 × 6 行** 网格并按容器剩余高度自适应拉伸，单元格保留最小高度，确保日历区域视觉上充满卡片内容区。
- **日历尾格补齐（P1）**：每月日历除月初前置空白外，需补齐月末尾部占位空白格，总单元格固定为 **42**（`7×6`），确保你选中的日历容器框被完整网格占满。

## 布局与结构

### 3.1 整体布局

- **布局模式**：整页大屏无顶栏；`zht-root` 占满视口高度，主体为 **左侧指标栏 + 中间地图列 + 右侧分析看板** 三列 flex（`zht-body`）。
- **高度链（地图可见性）**：`index.html` 内为 `html, body, #root` 设置 `height: 100%`，与 `.zht-root { height: 100%; min-height: 100dvh; }` 衔接，避免去掉顶栏后 `#root` 仅 `min-height` 导致子级 `flex:1` 地图区高度为 0、画布空白；`.zht-map-shell` 另设 `min-height: min(480px, 50dvh)` 作为兜底。
- **左侧栏行高自适应稳定性**：`index.tsx` 里左栏 `ResizeObserver` 回调通过 `requestAnimationFrame` 节流，且仅当 `--zht-stat-row-h` 或 `zht-left--scroll` 状态变化时才写回 DOM，避免连续回写触发 `ResizeObserver loop completed with undelivered notifications`。
- **容器宽度**：左侧栏约 **392px**（原型量级），中间地图列 `flex:1` `min-width:0`，右侧栏约 **400px**（`min(400px,100vw)`，≤1100px 时约 **320px**），右侧栏整体纵向滚动。
- **关键尺寸**：
  - 指标卡片：三列网格（窄屏降为两列），卡片最小高度约 **71px**（对齐稿中卡片比例）。
  - 右侧环形图容器高度约 **200px**（ECharts `resize` 随栏宽变化）；看板整体纵向滚动。

### 3.2 响应式适配

- **宽屏**：完整三列指标与右侧看板同原型量级。
- **中窄屏（≤1100px）**：左侧栏缩至 **280px**，指标两列；右侧看板宽度收窄为 `min(320px,100vw)` 避免溢出。
