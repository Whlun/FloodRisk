# 德清内涝-风险等级管理

## 说明

侧栏标题为「**风险自动定级**」（`sidebar-menu-title`）。

本原型实现导则**指标体系法**：指标值按附录 F（**相等间隔法**）自动匹配**评估指标分数 F**，再按附录 E（**层次分析法参考权重 ω**）加权求 V，无单独「隐患评估」环节。

**指标计算方法分工**（与导则 5.6.2–5.6.3 一致）：

| 环节 | 导则依据 | 系统实现 |
|------|----------|----------|
| 标准分 F | 附录 F 相等间隔法 | 「风险指标管理」赋分规则；普查/试算自动匹配 |
| 权重 ω | 附录 E 层次分析法（参考） | 预置附录 E 结论权重；架构图可手工调整 |
| 综合分 V | 公式 5.6.1 / 5.6.2 | `scoreCalculator` 双层加权 |

附录 E 标题「（参考）」表示 AHP 用于**编制导则时推导权重**；定级评估时默认直接引用预置 ω。若需本地化调整，可在「指标架构图 → 指标权重配置」中手工编辑 ω。

## 业务流程

```text
内涝普查定级（按点定级/更新定级） → 防灾减灾指标信息（按时间维护全县 V₄） → 风险变更记录（查询审计）
```

| 阶段 | 菜单 |
|------|------|
| 内涝普查定级 | 内涝定级 / 内涝普查定级（按时间维护普查快照；列表筛选支持**易涝点**、**普查时间范围**、点位类型、普查状态；列表列名为**易涝点**、**点位类型**；**定级结果**列已定级时展示风险等级 Tag + **综合分 V**（四位小数）；「**数据引用**」列已引用记录展示 **当前引用** Tag；**引用**操作须普查已完成且**已定级**（未定级禁用并提示「没有定级不可引用」）；定级/更新定级确认后写入风险变更日志；**已是数据引用时「更新定级」**确认后将附录 B 推送到同易涝点其余普查记录；**同一易涝点仅可有一条数据引用**） |
| 防灾减灾指标信息 | 内涝定级 / 防灾减灾指标信息（按时间维护；列表筛选支持**配置时间范围**、**批次说明**、**填报人**、配置状态；「**数据引用**」列已引用记录展示 **当前引用** Tag；列表操作：详情/编辑/新增）；填报表单**不展示**标签旁实时赋分 Tag（分档以下拉/数值为准，保存时自动匹配）；强排能力通栏、两完成率并排；填报表单展示架构图**已启用**且一级因子为防灾减灾救灾因子的全县指标（`survey.scope=region`，与「普查时必填」无关；一级因子为防灾减灾时作用域固定全县，保存时自动校正） |
| 风险变更记录 | 内涝定级 / 风险变更记录（只读列表：展示定级确认产生的等级变更日志；支持条件查询、字段管理；**详情弹窗**含本条明细及同易涝点历史定级时间线） |

定级条件：该点**普查已完成**（指标普查 Tab **数据完整度 100%**，且满足「普查时必填」项）+ 防灾减灾指标信息中存在**已设为数据引用**的完整记录；定级时由普查值自动映射本点 V₁–V₃，合并该版本的 V₄。保存时未达 100% 记为**草稿**，不弹出定级确认；列表「定级/更新定级」仅对已完成普查显示。**定级操作入口在内涝普查定级**，风险变更记录页不提供定级功能。

**演示数据**（`deqing-waterlogging-survey-seeds.ts` / `deqing-waterlogging-points.ts`）：附录 B 与「指标普查」成对维护；已完成普查记录的数据完整度为 100%（仅统计指标普查 Tab）；已定级记录的风险变更日志数值与 `ratingResult` 一致。草稿示例「新市镇永安街低洼段」为约 33% 完整度（3/9 项指标 + 部分附录 B）。

**普查详情只读**：弹窗 `disabled` + `DynamicSurveyFields` 传入 `readOnly`；条件赋分控件（如排水系统设计重现期）在只读时不得因「条件已满足」而恢复可编辑。

**定级确认弹窗**：大尺寸左右分栏（左：指标评分结构图，右：风险等级与 V₁–V₄ 摘要）；弹窗主体尽量不纵向滚动，左侧各一级因子列内可滚动查看二级指标。

**新增普查**：须填写**普查时间**与可选**批次说明**；每条记录为一次普查快照。基本信息 Tab 先选**所属区划**（可选**德清县**表示全县，或选具体乡镇/街道），再选**易涝点（主数据）**；易涝点下拉仅展示所选范围内尚未建立普查记录的台账点位。主数据演示库含四种隐患点类型各 2 条（`deqing-waterlogging-point-registry.ts`）。**指标普查 Tab** 展示：已开启「**参与内涝普查定级**」或勾选「**普查时必填**」、作用域为单点、适用当前易涝点类型、且**未**绑定附录 B 专用信息的指标（与架构图**启用**无关；未启用项标注「未启用·暂不计分」）。**普查完成 / 100% 完整度**按上述填报范围统计。**定级计分**仅使用架构图中**已启用**且配置完整的指标及合法 ω。无可用指标时展示原因说明（未参与普查、附录 B 填报位、类型不匹配等）。

**附录 B 现场信息**：共性字段（积水深度、调蓄/泵站、监测与预案、地区重要程度等）常显，分区标题旁 **?** 说明填报范围；**历史灾情**为四种类型共用模块（「有历史灾情」选「是」后填损失数值，亦可作为条件赋分来源，说明见分区标题 **?**）；最大历史积水深度、是否有调蓄池/排涝泵站/监测设施、积水报警装置运行正常、是否有内涝应急预案等字段标签旁有 ? 提示「优先根据易涝点基础信息自动填充」；选定易涝点类型后展开该类型**专用信息**区块——下凹式含高程/下凹深度/汇水面积等；**地下空间含人行、车行出入口与室外地面高程差 H（m）两项（均必填）**；指标填报形态为「附录 B 多数值子项（聚合取不利档）」，各子项分档在「赋分规则」Tab 配置（打开编辑时可从导则种子灌入）；默认定级取不利档；赋分方式三选一可改；不在指标普查 Tab 重复填报，仍计入完整度；**城市低洼路段含道路纵坡 S（%）**（表 5.3.11，收水能力分档依据，与下凹式/隧道「纵坡度」指标不同）；隧道其余指标在「指标普查」Tab。**地区重要程度**联动下凹式/低洼路段「排水系统设计重现期」P 阈值（表 5.3.3）；**地下空间**同指标按表 5.3.8 为「满足/不满足设计标准」两档下拉（非 P 年数值）。与指标普查中的**地区重要性**为不同概念，**无自动映射**。**普查元信息**（弹窗底部，Tabs 下方以分割线隔开，与表单字段同级）：**普查时间**、批次说明、采集人姓名、单位、**附件（PDF 上传，最多 5 个，单文件 ≤15MB）**、备注；保存时普查时间同步至记录 `surveyAt` 与附录 B `collectedAt`。附件存于 `surveyPayload.appendixB.attachments`（原型为浏览器 data URL）；详情模式可查看/下载。数据引用同步附录 B 时一并同步附件列表。

**适用隐患点类型**：孕灾因子（`FORMATION`）每条指标选**一种**具体类型；致灾/承灾/防灾减灾固定为「通用」，多选隧道等类型不参与计算（保存时自动规范为 `GLOBAL`）。

**风险指标管理 · 单一体系（空白自建）**：运行时仅维护一份 `RiskIndicatorRow[]`；冷启动与无工作区文件时列表为 **0 条**，不自动注入 `deqing-waterlogging-risk-indicators.ts` 导则种子。编辑/保存/试算均经 `indicatorNormalize.ts` 规范化，**不再**在打开编辑时用种子 `conditionalScoring` 覆盖本地配置。**所有指标均可删除**（无「导则内置不可删」）；列表操作列提供「详情 / 编辑 / 停用·启用」（启用状态在指标架构图中调整）。用户新增指标**新建保存后默认停用**（仅表示暂不参与 V 计分，不阻塞普查填报），不可在基本信息中直接勾选启用，须在**指标架构图**中配置同级 ω 并切换启用后方可定级计分。用户新增指标可在**编辑弹窗**左下角删除，须**先停用**后方可确认，启用时「删除指标」置灰并提示先停用。列表含 **赋分规则**、**配置状态**、**数据状态**（默认/修正）、**启用状态** 等列，与筛选区「全部状态」联动。

**风险指标管理 · 新建向导与赋分规则**：点击「新增」打开**分步向导**（基本信息[含参与普查定级/普查必填、普查字段键与占位说明] → 赋分规则[场景切换 + 赋分配置] → 确认预览）；第二步**仅展示与第一步「普查填报方式」兼容的赋分场景**（由 `wizardDraft` 单一数据源驱动，不展示不兼容卡片）；离开基本信息步时按填报方式应用默认场景模板；`valueType` 表单项全向导常驻注册，避免分步卸载丢失；纵坡度等须在第一步选「填数值」后选**数值分档**；选后自动填充最小可计算配置；选定场景后下方不再重复展示「统一/条件/复合」三选一；配置完整时不展示「配置就绪」绿条；确认步展示**建议权重**（同级均分）。编辑已有指标时弹窗为 **基本信息**（含参与普查定级/普查必填）+ **赋分规则** 两 Tab；赋分规则 Tab 含左右**可视化预览**、**配置就绪清单**、场景模板切换。切换赋分方式后列表「赋分规则」列与保存结果以 `survey`/`conditionalScoring` 与 `scoringRuleMode` 对齐解析（避免隐藏字段未同步仍显示「统一赋分档」）。条件赋分默认**流程预览**（只读流程图）；修改条件来源、分支与赋分档须切换到**表单配置**。复合数值赋分同样在赋分规则区**表单配置 / 流程预览**切换（详情默认流程预览）。新建保存后提示**前往架构图启用并配权重**；架构图启用前校验配置完整性（不完整时开关禁用并提示）。内涝等级试算前会校验启用指标配置是否完整。自动化验收：`npm run check:deqing-indicators` 覆盖种子结构合法性、未配齐区间时的待完善状态、五类新建场景模板、统一/条件/复合赋分不变量与低洼辅助条件流（`tests/deqing-indicator-readiness-matrix.test.ts` 等）。

**风险等级管理**：可配置综合分 V 与风险等级映射。Card 标题「风险等级管理」；工具栏「新增等级」「恢复默认」。列表含排序、编码、名称、标签色、分数区间、说明、启用状态、来源（预置/自定义）；导则预置三档（表 5.6.1）可编辑名称/区间/颜色/排序等，**不可删除**；用户新增等级默认停用，须先停用后方可删除；启用时校验区间不与其它启用等级重叠，且至少保留一档启用。编辑弹窗可维护等级编码（预置档编码只读）、排序（越大表示风险越高，用于变更记录升高/降低推断）。随工作区一并写入 `workspace-data.json`；恢复默认重置为导则预置三档（表 5.6.1）。

**风险指标管理 · 一级因子**：新建/编辑指标「基本信息」中一级因子下拉每项展示导则 2.0.9–2.0.12 释义（危险性/敏感性/脆弱性/抵御与恢复性）；选定后表单项下方同步展示当前因子说明。

**工作区持久化（本地开发服务）**：配置与业务数据写入项目内 `src/prototypes/deqing-waterlogging-risk/workspace-data.json`，由开发服务 API `GET/PUT /api/deqing-waterlogging/workspace` 读写；**重启 `npm run start` 后数据保留**，换浏览器也能读到同一份。首次启动若服务端尚无文件、但浏览器里仍有旧版 localStorage 数据，会自动**迁移一份**到该 JSON 文件。首次加载空白自建版本时，若工作区 meta 未标记 `blankSlateIndicators`，会**一次性将 `indicators` 置为 `[]` 并写回**（升级前请自行备份 JSON）。单元测试仍使用内存 mock，不走该 API。

**说明（remark）**：在「基本信息」Tab 维护，**每条指标独立一份**；打开编辑弹窗会先重置表单再填入当前指标，避免串到上一指标的说明。指标架构图二级指标名称旁 **?** 悬停展示；在「赋分规则」等其它 Tab 点保存时仍合并写入；清空后保存为无说明，**刷新页面仍保持**（`dq-waterlogging-risk-indicators-v2`）。

**赋分说明（scoreExplanation）**：在「赋分规则」Tab 维护（多行文本，每行一条）；导则预置指标已写入与原 ? 悬停一致的默认文案（含数值合理范围、附录 F 分档、导则表号、防灾减灾数据来源等），可编辑后保存；随工作区文件持久化。普查、试算、防灾减灾配置等表单项 **?** 优先展示赋分说明；排水重现期、带辅助条件的指标等填报场景可追加动态行（当前地区阈值、当前条件指标取值等）。清空赋分说明时回退为按赋分档自动生成的简要对照。在其它 Tab 保存时仍合并写入，不会清空。

**普查填报方式**：下拉分档 / 填数值 / 是·否；**单位**仅数值型显示、**选填**（填写后写入分档描述与普查展示；新建向导与编辑弹窗：一级因子与普查填报方式同一行，单位在下一行）。

**赋分规则 Tab 布局**：自上而下为「按条件切换赋分（可选）」→「赋分档」→「赋分说明」。条件赋分开启后支持 **流程预览 / 表单配置** 切换：流程预览为只读流程图（开始→读取条件→菱形判断分支→各路径赋分档→输出标准分）；**表单配置**为唯一编辑入口，二者互斥展示、不重复罗列。赋分档行内校验提示为「请填写分档描述」「请填写标准分」；保存时若必填未填，顶部 **message** 列出缺失项并自动切换到对应 Tab（基本信息 / 普查关联 / 赋分规则），表单项标红；不向调试面板抛出未捕获 Promise。**用户新增指标编码**：系统按一级因子自动生成（`HZ_U001`、`FM_U002` 等，只读不可改），并默认同步「普查字段键」；保存前若普查字段键仍为空则回退为指标编码。导则预置指标编码不变。**条件字段（本点其他指标）**：按「基本信息」中的一级因子与适用隐患点类型过滤——孕灾因子仅展示同类型孕灾数值型指标 + 全县通用数值型指标（不再出现其它子集同名项如多条「纵坡度」）；致灾/承灾/防灾减灾仅展示全县通用数值型指标；未选适用类型时禁用并提示先填基本信息。**配置时含未启用指标**（选项标注「未启用」），便于新建后互引条件；「按条件数值切换分档表」仅列数值型，「按条件切换赋分档」另含下拉/是·否型；未纳入指标普查或「多数值聚合赋分」主指标不出现在列表。无匹配项时下拉展示原因说明。

**赋分方式（三选一）**：每条指标显式存储 `scoringRuleMode`（统一赋分档 / 条件赋分 / 复合数值赋分），赋分规则 Tab 的 Segmented 读写该字段；`survey.inputVariant` 与 `conditionalScoring.enabled` 由程序同步。选择「条件赋分」后不再单独展示「启用条件赋分」开关，配置区直接展开。打开编辑时在 `setIndicatorOnForm` 一次性灌入预置配置；复合子项可点击「恢复默认复合配置」。切换模式后保存，重开保持用户选择。

**下拉选档（enum）**：赋分规则 Tab 配置「分档名称 + 标准分 F + 分档说明（选填）」；填写分档说明后，普查下拉选项及选中结果下方展示附注。用户普查时手选档位，按选项匹配 F。

**复合数值赋分**：赋分规则 Tab 可配置**多个**条件字段子项（内涝基本信息 / 本点数值型指标），各子项数值分档后按「取 F 大 / 取 F 小」聚合；可选**前置门控**（内涝基本信息布尔项满足时直接取 F）。本指标不在指标普查重复填报。数值分档比较符含 **=**（零值表示「无」）。

**数值指标**：标签旁 ? 显示合理范围与附录 F 分档；超出 `numericIndicatorConstraints` 范围不可保存。数值型统一赋分须在 `scoreRules` 为每一档配置 `numericMatch`；**不**按导则编码自动补全区间，须在建指标时手动配齐。**数值型统一赋分**赋分档表列为「匹配区间 → 标准分 F → 分档描述（展示，可改）」：先配区间与分数，描述由 `formatNumericMatchLabel` 自动生成（通用符号为「值」，并拼接基本信息中的**单位**；单位变更时仅刷新仍为自动生成的描述，手改保留）；枚举/布尔型无匹配区间列，仅分档描述 + 标准分。通用新建「数值分档」仅预置四档标准分 F（0.25～1），匹配区间由用户按含义配置。

**条件赋分**（向导场景「条件赋分」/ `scoringRuleMode: conditional`）：用户先选**条件来源类型**（内涝基本信息 `appendix_b` / 本点其他指标 `indicator`），再选**条件字段**，为各分支配置匹配条件与赋分档；`survey.inputVariant` 保持 `default`，不自动注入辅助条件。切换来源类型会清空条件字段待重选，**不会**因 key 暂空而整表回退为默认「内涝基本信息」；仅 `auxiliary_then_select` / 指标普查辅助条件工作流自动对齐辅助条件包。条件来源与条件字段均为可搜索下拉，两类数据均可选。**数值型**且赋分方式为「按条件数值切换分档表」时，各分支内赋分档与「数值分档」一致：为每档配置匹配区间与标准分 F，不再使用单一阈值 + 满足/不满足两档。表单配置区中「条件赋分方式」「条件字段」「条件分支」及分支内「匹配取值」等字段说明均通过标签旁 **?** 悬停展示（不再使用表单项 `extra` 或分隔线下灰色说明行）。**流程预览**：离散条件命中分支后，若分支内已配 `numericMatch` 分档，则展示「按填报值匹配区间」与各档结果；仅旧数据仍用分支级单阈值比较时展示「满足/不满足」二元节点。详情弹窗默认打开流程预览；切换视图时保留表单 DOM 注册，并以打开时的指标快照回退，避免只读页误报「配置不完整」。

**辅助条件 + 条件赋分**（高级 `survey.inputVariant = auxiliary_then_select` + `survey.auxiliaryCondition`，或导则种子如 `FM_LL_COLLECT`）：默认 `indicator_census`、名称「辅助条件」、`fieldKey` 为 `{code}_COND`；条件分支默认为「分支 1 / 分支 2」，**不预填**数值条件，保存前须自行配置。辅助条件在「指标普查」填报时，条件来源固定为「本点其他指标」，条件字段展示「辅助条件」等中文名称，界面不展示裸 `fieldKey`（如 `FM_U002_COND`）。**新建向导分步**：基本信息字段（`level1` / `code` 等）须保持 Form 注册（隐藏而非卸载），避免赋分规则步 `useWatch` 读空导致条件字段退回 Select 裸显。条件名称、填报位置等可在「高级」中开启「先填条件字段，再选本分档」后调整。**两步逻辑**：① 辅助条件数值比较命中分支；② 各分支配置赋分——下拉分档时主指标选档，填数值时按分支内区间匹配 F。

**表格预览 / 表格下载**（风险指标管理筛选区为「表格预览」，内涝普查定级筛选区为「表格下载」）：按当前「纳入普查」或「普查时必填」的指标，生成四种易涝点类型（下凹式立交桥/下穿道、隧道、地下空间、城市低洼路段）的**附录 B 样式信息采集表**预览；Tab 切换类型；支持**下载 PDF**（当前 Tab）与**浏览器打印**（仅打印预览表体）。下凹式含导则附录 B 专用项；其余类型专用指标列在「指标普查」区块。指标普查行（数值/下拉/是·否）在**左侧标题栏**（指标名称下方）展示**赋分说明**全文（与风险指标管理「赋分规则 → 赋分说明」及普查表单 **?** 一致；含合理范围、导则表号、分档含义等）；右侧仅保留填空、单位或选项勾选区。

**内涝等级试算**（入口：风险指标管理筛选区「内涝等级试算」按钮，**弹窗**打开，非侧栏菜单）：易涝点指标自行填报；**防灾减灾因子默认引用「防灾减灾指标信息」数据引用版本**，可修改且仅影响本次试算；「防灾减灾救灾因子」分区标题后展示引用 Tag，**「恢复防灾减灾指标信息引用」**按钮与该标题同一行靠右；试算不展示标签旁赋分 Tag（分档以下拉/数值为准）。表单分区采用浅底卡片 + 左侧色条二级标题（弱于 Card「指标试算填报」），致灾/孕灾/承灾/防灾减灾等区块层级清晰。双列栅格顶对齐、标签在列宽内换行（必填星号与标题同一行，标签与输入框间距紧凑），整行/成对规则与普查表单一致（如应急强排能力整行、6h/2h 响应率并排）；排水系统设计重现期独占整行。弹窗宽约 **1400px**（随视口收缩），左侧表单区略宽于右侧试算结果；双列同行标签区等高对齐。桌面端仅左侧「指标试算填报」卡片内容区纵向滚动，顶部说明/点位类型与右侧试算结果固定可见；右侧试算结果顶部突出展示**风险等级**，综合分 V 以次要文字展示。可「填充易涝点演示值」（写入与普查演示一致的附录 B，并按指标 **code** 映射到当前 **fieldKey**；数值档取可命中赋分区间）或「恢复防灾减灾指标信息引用」。切换点位类型不再被初始化 effect 覆盖已填内容。工具栏**点位类型**下拉收起约 260px 宽；展开面板单独加宽（约 560px）以展示导则类型释义（与指标架构图类型徽章 **?** 一致）；选中项旁有 **?** 可再次查看。

**风险变更记录**：在内涝普查定级「定级/更新定级」确认时自动写入；变更类型含首次定级、等级升高/降低、结果更新等；列表支持按**易涝点下拉**、隐患点类型、变更类型、新风险等级、变更时间范围筛选，以及字段显示管理；详情以**居中弹窗**展示本条定级明细及该易涝点（`registryId`）全部历史变更时间线。
