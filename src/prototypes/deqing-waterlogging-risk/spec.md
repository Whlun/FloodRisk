# 德清内涝-风险等级管理

## 说明

侧栏标题为「**风险自动定级**」（`sidebar-menu-title`）。

本原型实现导则**指标体系法**：指标值按附录 F（**相等间隔法**）自动匹配**评估指标分数 F**，再按附录 E（**层次分析法参考权重 ω**）加权求 V，无单独「隐患评估」环节。

**指标计算方法分工**（与导则 5.6.2–5.6.3 一致）：

| 环节 | 导则依据 | 系统实现 |
|------|----------|----------|
| 标准分 F | 附录 F 相等间隔法 | 「风险指标管理」赋分规则；普查/试算自动匹配 |
| 权重 ω | 指标体系法权重 | 评价版本中手动配置；编辑器提供「按比例归一化」与「恢复默认」（回退至上次保存/打开弹窗时的基准） |
| 综合分 V | 公式 5.6.1 / 5.6.2 | `scoreCalculator` 双层加权 |

权重 ω 在「评价版本」中配置；新建版本可基于当前定级引用复制，或使用系统默认权重后手工调整。

## 业务流程

```text
内涝普查定级（按点定级/更新定级） → 防灾减灾指标信息（按时间维护全县 V₄） → 风险变更记录（查询审计）
```

| 阶段 | 菜单 |
|------|------|
| 内涝普查定级 | 内涝定级 / 内涝普查定级（按时间维护普查快照；页顶蓝色提示展示**当前定级引用评价版本**（V00x）与**当前定级引用等级版本**（L00x），架构提示含**查看详情**跳转指标评价管理详情弹窗；列表筛选支持**评价版本下拉**（占位提示，默认不选即全部）、**易涝点**、**普查时间范围**、点位类型、普查状态；列表列含**评价版本**（优先 `surveyArchitectureVersionNo`，否则按 `surveyArchitectureRefId` 解析，与详情弹窗一致；仍无绑定时回退定级引用；已定级且缺普查绑定时可取 `ratingResult.architectureVersionNo`）、**等级版本**（已定级时展示 `ratingResult.riskLevelVersionNo`，未定级为 —）；**定级结果**列已定级时展示风险等级 Tag + **综合分 V**（四位小数），悬停可查看**评分方案：V00x**与**等级方案：L00x**；「**数据引用**」列已引用记录展示 **当前引用** Tag；**引用**操作须普查已完成且**已定级**（未定级禁用并提示「没有定级不可引用」）；定级/更新定级确认后写入风险变更日志；**已是数据引用时「更新定级」**确认后将附录 B 推送到同易涝点其余普查记录；**同一易涝点仅可有一条数据引用**；**编辑**弹窗底部为「取消」「删除」「保存」（删除在保存左侧，带二次确认；新增无删除）） |

定级条件：该点**普查已完成**（指标普查 Tab **数据完整度 100%**，且满足「普查时必填」项）+ **当前定级引用评价版本**下防灾减灾指标信息中存在**已设为 V₄ 数据引用**的 completed 记录 + **评价版本**中存在**已设为定级引用**且权重校验通过的 completed 记录 + **等级版本**中存在**已设为定级引用**且区间校验通过的 completed 记录；定级时由普查值自动映射本点 V₁–V₃，合并该评价版本下 V₄ 数据引用记录的全县防灾减灾值，并按定级引用评价版本版本的 ω 与启用状态计分；综合分 V 再按**当前定级引用等级方案**映射风险等级。保存时未达 100% 记为**草稿**，不弹出定级确认；列表「定级/更新定级」仅对已完成普查显示。**定级操作入口在内涝普查定级**，风险变更记录页不提供定级功能。

**防灾减灾与评价版本对齐**：内涝普查定级与防灾减灾指标信息均为**按评价版本绑定的普查快照**（前者按易涝点、后者全县共用 V₄）。**V₄ 数据引用** scoped 到**当前定级引用评价版本**——每个评价版本可各保留一条引用标记，但 live 定级仅读取与定级引用 `architectureRefId` 一致且 `activeForRating` 的记录。切换定级引用（如 B→A）后，须在 A 下新建/完成防灾减灾填报并设为 V₄ 数据引用，否则无法定级；B 时代记录保留作历史审计，不可跨评价版本引用。

**逐条绑定评价版本（审计可追溯）**：普查（`surveyArchitectureRefId/At/VersionNo`）、防灾减灾（`versionNo` P001… + `architectureRefId/At/VersionNo` 绑定评价版本）、定级结果（`architectureVersionNo`、`riskLevelVersionNo`、`preventionVersionNo`）与风险变更日志均在**保存/定级时**写入当时采用的方案编号（评价 V001…、等级 L001…、防灾减灾 P001…）。筛选栏为**评价版本下拉**（占位「筛选评价版本」，**默认不选**即展示全部记录，可清空；选定后按版本筛选）；**新建**普查/防灾减灾时，若未选具体版本则绑定当前定级引用评价版本，若已选则绑定该版本。编辑已有记录**保留**原绑定；切换明年定级引用后，历史行仍展示当时版本。旧演示数据须重新生产，**不做**自动 infer 补写。

**考核方案与普查绑定**：新增普查前须在筛选栏选择一条 **completed** 评价版本；每条普查记录绑定 `surveyArchitectureRefId` / `surveyArchitectureRefAt` / `surveyArchitectureVersionNo`（创建时写入下拉选中项）。**须填报指标** = 该方案中**已启用**且参与普查/普查必填的单点指标（含附录 B 绑定项计入完整度）。**首次定级**采用页顶**当前定级引用**评价版本与等级版本计分，定级结果写入 `architectureVersionNo` / `riskLevelVersionNo`；若定级方案与普查绑定方案不同，定级确认弹窗可对比展示。

**更新定级与版本（KPI 不追溯换标）**：「更新定级」对同一条已完成普查记录按**上次定级锁定**的评价版本（`ratingResult.architectureRefId` / `architectureVersionNo`）与等级版本（`ratingResult.riskLevelRefId` / `riskLevelVersionNo`）重新计分，**不随页顶当前定级引用变更**——与考核 KPI 一致，已发生定级不能换标准。普查指标原始值（`surveyPayload`）不变，完整度仍按**普查绑定**评价版本统计；计分权重/启用指标与 V→等级映射均取**锁定方案**；V₄ 优先取锁定 `preventionVersionNo` / `preventionRefAt` 对应记录，否则取该锁定评价版本下的 V₄ 数据引用（**不是**页顶当前定级引用下的 V₄）。旧数据若 `ratingResult` 缺版本字段，从风险变更日志与 V₄ 引用反查补全。页顶定级引用已切换时，确认弹窗蓝色提示「页顶定级引用已变更，本次仍按锁定方案计分」。列表「定级」悬停提示当前定级引用；「更新定级」悬停提示锁定版本编号。

**演示数据**（`deqing-waterlogging-survey-seeds.ts` / `deqing-waterlogging-points.ts`）：附录 B 与「指标普查」成对维护；已完成普查记录的数据完整度为 100%（仅统计指标普查 Tab）；已定级记录的风险变更日志数值与 `ratingResult` 一致。草稿示例「新市镇永安街低洼段」为约 33% 完整度（3/9 项指标 + 部分附录 B）。

**普查详情只读**：弹窗 `disabled` + `DynamicSurveyFields` 传入 `readOnly`；条件赋分控件（如排水系统设计重现期）在只读时不得因「条件已满足」而恢复可编辑。新增/编辑/详情弹窗**标题后**展示本普查绑定的**评价版本** Tag（评价版本 V001…）。

**定级确认弹窗**：大尺寸左右分栏（左栏自上而下：更新定级时的蓝色方案提示、指标评分结构图；右：风险等级与 V₁–V₄ 摘要）；标题「定级确认」/「更新定级确认」后展示**评价版本**与**等级版本** Tag；右侧结果区（与内涝计算器一致）在综合分下方展示评价/等级版本 Tag，摘要 Descriptions 仅含**防灾减灾引用**与 V₁–V₄ 分项。**更新定级**时左栏顶部蓝色提示沿用锁定方案（不含括号补充说明）；若页顶定级引用与锁定方案不一致，另附蓝色对比说明（均在结构图上方）。弹窗主体尽量不纵向滚动，左侧各一级因子列内可滚动查看二级指标。

**新增普查**：须填写**普查时间**与可选**批次说明**；每条记录为一次普查快照，**创建时绑定筛选栏选中的评价版本**（决定须填报指标范围）。基本信息 Tab 先选**所属区划**（可选**德清县**表示全县，或选具体乡镇/街道），再选**易涝点（主数据）**；易涝点下拉仅展示所选范围内尚未建立普查记录的台账点位。主数据演示库含四种隐患点类型各 2 条（`deqing-waterlogging-point-registry.ts`）。**指标普查 Tab** 展示：本普查绑定方案中**已启用**、已开启「**参与内涝普查定级**」或勾选「**普查时必填**」、作用域为单点、适用当前易涝点类型、且**未**绑定附录 B 专用信息的指标。**普查完成 / 100% 完整度**按上述范围统计。**定级计分**使用**当前定级引用**架构中已启用且配置完整的指标及合法 ω。无可用指标时展示原因说明（方案未启用、未参与普查、附录 B 填报位、类型不匹配等）。

**附录 B 现场信息**：共性字段（积水深度、调蓄/泵站、监测与预案、地区重要程度等）常显，分区标题旁 **?** 说明填报范围；**历史灾情**为四种类型共用模块（「有历史灾情」选「是」后填损失数值，亦可作为条件赋分来源，说明见分区标题 **?**）；最大历史积水深度、是否有调蓄池/排涝泵站/监测设施、积水报警装置运行正常、是否有内涝应急预案等字段标签旁有 ? 提示「优先根据易涝点基础信息自动填充」；选定易涝点类型后展开该类型**专用信息**区块——下凹式含高程/下凹深度/汇水面积等；**地下空间含人行、车行出入口与室外地面高程差 H（m）两项（均必填）**；指标填报形态为「附录 B 多数值子项（聚合取不利档）」，各子项分档在「赋分规则」Tab 配置（打开编辑时可从导则种子灌入）；默认定级取不利档；赋分方式三选一可改；不在指标普查 Tab 重复填报，仍计入完整度；**城市低洼路段含道路纵坡 S（%）**（表 5.3.11，收水能力分档依据，与下凹式/隧道「纵坡度」指标不同）；隧道其余指标在「指标普查」Tab。**地区重要程度**联动下凹式/低洼路段「排水系统设计重现期」P 阈值（表 5.3.3）；**地下空间**同指标按表 5.3.8 为「满足/不满足设计标准」两档下拉（非 P 年数值）。与指标普查中的**地区重要性**为不同概念，**无自动映射**。**普查元信息**（弹窗底部，Tabs 下方以分割线隔开，与表单字段同级）：**普查时间**、批次说明、采集人姓名、单位、**附件（PDF 上传，最多 5 个，单文件 ≤15MB）**、备注；保存时普查时间同步至记录 `surveyAt` 与附录 B `collectedAt`。附件存于 `surveyPayload.appendixB.attachments`（原型为浏览器 data URL）；详情模式可查看/下载。数据引用同步附录 B 时一并同步附件列表。

**适用隐患点类型**：孕灾因子（`FORMATION`）每条指标选**一种**具体类型；致灾/承灾/防灾减灾固定为「通用」，多选隧道等类型不参与计算（保存时自动规范为 `GLOBAL`）。

**风险指标管理 · 单一体系（空白自建）**：运行时仅维护一份 `RiskIndicatorRow[]`（赋分规则与普查配置等**指标定义**）；列表**仅展示定义层**，不合并评价版本 overlay。**启用状态与 ω 存于「评价版本」快照**，在「指标评价管理」版本编辑器中维护。冷启动与无工作区文件时列表为 **0 条**，不自动注入导则种子。编辑/保存/试算均经 `indicatorNormalize.ts` 规范化。**所有指标均可删除**；列表操作列为「详情 / 编辑」。用户新增指标保存后须在**评价版本**中配置同级 ω 并启用后方可定级计分；筛选区提供前往指标评价管理的引导。

**风险指标管理 · 新建向导与赋分规则**：点击「新增」打开**分步向导**（基本信息[含参与普查定级/普查必填、普查字段键与占位说明] → 赋分规则[场景切换 + 赋分配置] → 确认预览）；第二步**仅展示与第一步「普查填报方式」兼容的赋分场景**（由 `wizardDraft` 单一数据源驱动，不展示不兼容卡片）；离开基本信息步时按填报方式应用默认场景模板；`valueType` 表单项全向导常驻注册，避免分步卸载丢失；纵坡度等须在第一步选「填数值」后选**数值分档**；选后自动填充最小可计算配置；选定场景后下方不再重复展示「统一/条件/复合」三选一；配置完整时不展示「配置就绪」绿条；确认步展示**建议权重**（同级均分）。编辑已有指标时弹窗为 **基本信息**（含参与普查定级/普查必填）+ **赋分规则** 两 Tab；赋分规则 Tab 含左右**可视化预览**、**配置就绪清单**、场景模板切换。切换赋分方式后列表「赋分规则」列与保存结果以 `survey`/`conditionalScoring` 与 `scoringRuleMode` 对齐解析（避免隐藏字段未同步仍显示「统一赋分档」）。条件赋分默认**流程预览**（只读流程图）；修改条件来源、分支与赋分档须切换到**表单配置**。复合数值赋分同样在赋分规则区**表单配置 / 流程预览**切换（详情默认流程预览）。新建保存后提示**前往架构图启用并配权重**；架构图启用前校验配置完整性（不完整时开关禁用并提示）。内涝等级试算前会校验启用指标配置是否完整。自动化验收：`npm run check:deqing-indicators` 覆盖种子结构合法性、未配齐区间时的待完善状态、五类新建场景模板、统一/条件/复合赋分不变量与低洼辅助条件流（`tests/deqing-indicator-readiness-matrix.test.ts` 等）。

**风险等级管理 · 版本列表**（侧栏「风险自动定级 / 风险等级管理」）：以**版本编号**（L001、L002…）为主键管理综合分 V 与风险等级映射；与评价版本**独立**维护，各自有「定级引用」。列表支持版本编号、配置时间范围、批次说明、维护人、配置状态筛选；列含版本编号、批次说明、配置时间、启用档数、区间校验、**定级引用**（`当前引用` Tag）、操作（详情/编辑/引用；**无删除**，版本删除仅在编辑弹窗底部）。新增时克隆当前定级引用配置或导则预置三档；详情/编辑为**居中弹窗**（宽约 1200px，内容区可纵向滚动），内嵌等级编辑器（表格**行内直接编辑**，无操作列、无第三层弹窗；导则预置三档可编辑区间与展示、编码不可改；自定义等级通过停用开关管理；启用时校验区间不重叠且至少保留一档启用；编辑器内「**恢复默认**」回退至打开弹窗时的已保存基准，撤销当前未保存修改；新增版本时基准为克隆自定级引用或导则预置三档）。**编辑**弹窗底部为「取消」「删除」「保存」（删除在保存左侧，带二次确认；新增无删除）；**详情**弹窗底部为「编辑」。须 `completed` 且区间校验通过方可设为定级引用。定级结果与变更日志记录 `riskLevelVersionNo`。内涝普查定级页顶展示「当前定级采用等级版本 L00x」蓝色提示，含**查看详情**跳转风险等级管理详情弹窗。

**条件赋分**（向导场景「条件赋分」/ `scoringRuleMode: conditional`）：用户先选**条件来源类型**（内涝基本信息 `appendix_b` / 本点其他指标 `indicator`），再选**条件字段**，为各分支配置匹配条件与赋分档；`survey.inputVariant` 保持 `default`，不自动注入辅助条件。切换来源类型会清空条件字段待重选，**不会**因 key 暂空而整表回退为默认「内涝基本信息」；仅 `auxiliary_then_select` / 指标普查辅助条件工作流自动对齐辅助条件包。条件来源与条件字段均为可搜索下拉，两类数据均可选。**数值型**且赋分方式为「按条件数值切换分档表」时，各分支内赋分档与「数值分档」一致：为每档配置匹配区间与标准分 F，不再使用单一阈值 + 满足/不满足两档。表单配置区中「条件赋分方式」「条件字段」「条件分支」及分支内「匹配取值」等字段说明均通过标签旁 **?** 悬停展示（不再使用表单项 `extra` 或分隔线下灰色说明行）。**流程预览**：离散条件命中分支后，若分支内已配 `numericMatch` 分档，则展示「按填报值匹配区间」与各档结果；仅旧数据仍用分支级单阈值比较时展示「满足/不满足」二元节点。详情弹窗默认打开流程预览；切换视图时保留表单 DOM 注册，并以打开时的指标快照回退，避免只读页误报「配置不完整」。
