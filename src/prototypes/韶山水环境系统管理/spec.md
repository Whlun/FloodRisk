# 韶山水环境系统管理

## 业务与功能

### 定位

与 **韶山水环境设施管理系统** 一致的湘潭风格管理后台：左侧导航 + 面包屑 + 主内容区；本原型聚焦 **系统管理**，包含 **报表中心** 与 **配置中心** 两大模块。

### 报表中心

六类报表子模块，**列表页布局对齐本地参考截图**（路径：`/Volumes/公司/项目/2026/韶山/系统截图`，重点 **`数据报表-常规报表.png`**、**`数据报表-异常数据统计.png`** 等）：

- **左侧**：自上而下为 **区域** 下拉、「监测对象」标题、排放单位/排口名称检索框、监测对象树（与湘潭左栏筛选一致）。**全部报表** 均为 **单选树**：一级为企业/断面等分组（不可选），二级为排口或监测点（单选叶子）；与水质综合报表交互一致。
- **右侧主区白底筛选条**：**日报 / 月报 / 年报** 在 **时间范围选择器之前** 增加 **监测项名称** 下拉（可搜索），选项随 Card 顶部五类数据切换：**地表水、污染源、雨洪排口、集中式污水处理设施** 为 **水质** 类监测项（与水质综合报表列一致）；**水文监测** 为 **流量 / 水位** 分组（与流量、水位综合报表列一致）；其后为时间范围、**搜索**。
- **右侧表格区**：图例下方、表格上方有 **报表明细** 行，**同一行右侧**集中放置表格编辑类操作：**导出 Excel**（全部报表仅此一种导出，无 PDF）、**导入**（日/月/年报无导入）、**新增**（仅水质/流量/水位，`add-btn`）、**批量编辑** 或 **批量删除**（依报表类型）、**字段**（`ColumnManager`，列显隐、排序、恢复默认）。报表 Card **无** 顶栏 `extra` 放上述按钮，避免与「报表明细」行重复。
- **右侧主区**：Card 内容区顶部为 **五类数据切换**（`Tabs` 线型，地表水 / 水文监测 / 污染源 / 雨洪排口 / 集中式污水处理设施；内容宽度、选中为下划线 + 主色字），各报表子页共用；其下为白底筛选条 — **日报/月/年** 时顺序为 **监测项名称**（见上条）、**时间范围**（水质/流量/水位为**日期时间**范围；**日报**为**日期**范围；**月报**为**月份**范围；**年报**为**年份**范围）、蓝色 **搜索**；**不在**筛选条再放「导出」，导出统一在 **报表明细** 行。**日 / 月 / 年报** 仅 **表格** 展示，**无**「表格 | 曲线」分段切换；**水质 / 流量 / 水位等综合报表** 右侧可有 **表格 | 曲线** 分段切换（与「常规报表」一致）。
- **表格模式**：明细表列由 **字段** 管理；分页默认 **24 条/页**。**日 / 月 / 年报** 不展示三色图例（列为统计字段）；**其余报表** 共用三色图例（**正常 / 超限 / 手工**）；水质表为二级表头 + 指标限值行；其它非周期报表为单层表头，主要数值/状态列按三色与图例一致（示例数据含 `*Flag`）。
- **曲线模式**（仅非日/月/年报）：内嵌图表 Card + 折线/柱状/饼图/雷达 Tab（上述导入/导出/字段等仅在 **表格模式** 的「报表明细」行出现）。
- **水质 / 流量 / 水位**：**新增**（弹窗字段与表格列一致，追加一行）、**批量编辑**（批量改参 + 删除选中）；**日 / 月 / 年报**：无新增、无批量删除、表格无行勾选。与设施管理同款按钮类名（`export-btn` / `add-btn`）；**无** 页顶业务说明段落与「通用能力」折叠说明，以表格与工具为主。**新增 / 编辑 / 详情 / 批量删除 / 批量编辑** 弹窗与 **配置中心各子页** 一致：`formModalStyles`、`wrapClassName={facility-crud-modal-wrap}`、表单 `className="config-center-modal-form"`，宽度 **640px**（宽表详情仍用 `min(1200px, 96vw)` 等原规则）；**详情** 弹窗 **无底部栏**，与配置中心一致，仅用 **标题栏关闭 / 蒙层点击 / ESC**（`footer={null}`）。

## 技术实现

- 入口：`index.tsx`；样式：`style.css`（自设施管理系统复制湘潭变量与侧栏/表格/按钮类名；根节点附加 `system-mgmt-standalone`）。**弹窗**挂载在 `body` 下，`.facility-crud-modal-wrap` 相关规则**不**再依赖 `.system-mgmt-standalone` 祖先，否则详情/表单弹窗内边距与页脚分隔不生效。  
- 图表：`echarts/core` 按需注册折线/柱状/饼图/雷达及必要组件，避免全量引入。  
- 数据：示例台账与报表行数据，前端内存维护；**配置中心**各子模块（含水利工程下 **七类** 对象、**流域信息** `watershedInitial`）均在内存中维护列表，支持增删查改（原型级）。流域子页实现见 `config-center-watershed-view.tsx`。

## 布局说明

- **无** 顶部一级导航；**侧栏顶栏标题**为「系统管理」（与面包屑首段一致）；左侧为「报表中心」「配置中心」两级菜单（父级展开/收起，子级切换页面）；**污染源信息**、**水利工程信息** 下均为 **三级菜单**（污染源：农村污水及集中处理设施、农业农村源、工业企业污染源；水利：闸坝、堤防、水库、水闸、圩区、堰坝、山塘），点击二级行展开/收起三级；**三级侧栏样式与生态整治「河湖长制 · 河道水体」一致**（`sidebar-submenu-nest-wrap`、分组行图标+标签+箭头、叶子项 `sidebar-submenu-nested` 缩进与选中圆点）。  
- 面包屑格式：`系统管理 / 报表中心|配置中心 / <当前子模块名>`；污染源子页为 `… / 污染源信息 / <子类名>`；水利工程子页为 `… / 水利工程信息 / <闸坝|…|山塘>`；**流域信息** 等为配置中心下**无再分组的二级项**，面包屑为 `系统管理 / 配置中心 / 流域信息`。  
- **配置中心·列表筛选**：水利工程（水库/堤防/水闸/闸坝/堰坝/圩区/山塘/河流）按对象代码、名称、位置及表格中的枚举列（类型、等别、建设情况等）拆分；**单位信息** 含组织编码、名称、类型、联系方式、信用代码、责任范围；**污染源三类** 按各表台账主键字段拆分（如农村污水：信用代码、组织机构、单位/运营单位、乡镇、设施类型、受纳水体、**所属区划**等）；与列表列含义一致，便于组合查询。  
- 默认进入：**水质综合报表**。

## 验收

- 侧栏可切换全部子模块，面包屑与主内容一致。  
- 报表类页面具备筛选区；表格模式下 **报表明细** 行具备导出/导入及字段管理；水质·流量·水位具备 **新增**（表格字段追加一行）与 **批量编辑**（含删选中）；日·月·年报 **无** 新增与批量、**无** 表格/曲线切换（仅表格）；水质·流量·水位等综合报表可有表格、图表 Tab 切换。  
- 配置中心各子模块（含 **水利工程下七类**及 **污染源三类**、遥感、园区、**流域信息** 等）均具备筛选/查询、Card 标题行上的 **导出/导入/新增**、编辑、删除（原型级）；**污染源三类**、**遥感监测情况**、**流域信息** 与 **水利工程信息（七类）** 另具备表格 **字段管理**。台账类 **导出** 已接 **.xlsx 全量字段**（导出行与当前筛选一致，列与字段管理定义一致，码表/区划等与列表可读文案对齐；**报表中心** 部分导出仍为原型示意者除外）。  
- `npm run typecheck` 通过；生产构建包含本入口且无编译错误。
