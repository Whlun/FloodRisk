# 应急协同

## 说明

应急协同原型（侧栏标题「应急协同」）：侧栏与样式对齐「生态整治」设施管理（`water-env-dashboard facility-mgmt-standalone`）；主区首行 **`breadcrumb-bar`** 仅为 **`breadcrumb-current`** 文案（形如「一级菜单 / 子页」），与生态整治「项目管理 / 项目档案」同款结构，**无**行首图标。全站列表与详情/编辑弹窗统一使用设施管理同款 **按钮语义色**（`search-btn` / `export-btn` / `add-btn` / `secondary-btn` / `action-btn`）、**详情弹窗 `detailModalStyles`**（与生态整治大型只读弹窗一致的可滚动高度）；**应急事件详情**等多段内容使用 **`DetailTabsIfMultiple`**（`src/prototypes/shared/detailTabsIfMultiple.tsx`）：**多于一个 Tab 时** 内层为 **`Tabs`**（`facility-detail-tabs` + `size="small"`），**仅一段内容时不展示 Tab 顶栏**。**描述列表** 全局样式见 `style.css`（与生态整治同源并补充详情 Tab 顶距规则）。**编辑弹窗**等需 **`activeKey` 受控切换** 的仍直接使用 **`Tabs`**。

- **应急事件信息**：列表、新增、编辑、详情；列表 **操作** 含 **详情**、**处置填报 / 填报信息**（判定见 `emergencyEventDisposalFilled.ts`：嵌套 **`eventDisposal`** 的联系电话、处置描述、处置完成时间任一 trim 非空，或处置图片非空，则视为已填报 → 文案 **填报信息**、`FileTextOutlined`、打开详情且默认 **「事件处置」** Tab；否则 **处置填报**、`FormOutlined`、打开编辑并定位 **「事件处置」**；均为 `className="action-btn"`）、**编辑**；**详情弹窗**为 **三个 Tab**：「**基本信息**」（登记与位置；**事件编号与事件名称**同一行；**河段或湖泊编码**与**所属区划**各占一行（先河段后区域；韶山市及下辖乡镇街道下拉，`addvcd` 存值、界面不手填编码）；**污染等级、预警级别**在**上报人**之前；**上报人、上报人联系电话**后接**事发时间**与**上报时间**（字段仍为 `reportTime`）；**事发经度/纬度**之后为 **「事发位置地图」**：使用 **MapLibre GL JS**；**底图**：与工业园区 **同源**，仅 **`PARK_MAPLIBRE_STYLE_URL`**（OpenFreeMap Liberty，`EMERGENCY_MAPLIBRE_BASEMAP_STYLE` 与之恒等），**无** Esri/OSM/Carto 等其它来源；**无事发坐标**时视图中心为 **韶山市人民政府**（`EMERGENCY_MAP_SHAOSHAN_GOVERNMENT_CENTER`）；**无点缩放**与 `park-boundary-maplibre.tsx` 再导出同源；`EMERGENCY_MAPLIBRE_VECTOR_STYLE_URL` 与底图 URL **同一常量**（别名导出，便于与旧文档对齐）；有事发经纬时 **zoom ≈ 13.2**；**`jumpTo` 默认使标记点居中**（详情 `resize` 后亦对齐；编辑随经纬/图钉变化）；**详情弹窗**展示行与列表 `rows` 按 `id` 对齐，**编辑保存后**经纬度、事发地点与地图等随列表刷新，无需关闭重开；**`NavigationControl` + 紧凑署名**；业务 **GeoJSON 圆点**（插在 `emergencyFirstSymbolLayerId` 所指注记层之前，与矢量底图叠放规则一致）；**图钉 #1677ff**；**Popup**；无有效经纬度时说明占位。**Modal + `Descriptions`** 内须**非零块级高度**；**延迟挂载 / `ResizeObserver` + 多拍 `resize`**；外层 **`.emergency-event-detail-map-shell`** 对齐 `.park-fz-map-shell`，内层地图区 **300px 高** 对齐 `.park-boundary-map`；**情况描述**在**事发原因**紧前。列表/详情中 **接报时间** 展示为 **上报时间**；**无**「分级与上报」独立分组；**无**行政区编码字段）、「**事件处置**」（无「处置描述」字段；其余处置字段与**处置图片**）、「**事件评估**」（只读 **Descriptions**；多条时顶部 **Select** 切换；无关联时 Empty）。**事件编号**与生态整治「河湖长制 — 事务列表」**事务编号**栏一致：**只读 Input** + **extra** 说明生成规则；新增占位「保存后显示编号」，保存时按 **水应〔年〕MMDD-序号** 自动生成，编辑展示已生成编号。**事发地点**下为 **MapLibre 地图选点**（`EmergencyEventFormMap`：**Esri 栅格底图** + 园区同源 **center / zoom**；图钉 **#1677ff**；**可拖动图钉**；**外壳 + host**、**300px 高**；**单击标点**（`map.on('click')` + `document` 捕获 + 画布 `pointer` 备用）；与 **经度、纬度、事发地点** 联动；`ResizeObserver` 挂在外壳）。**处置状态**仅在 **「事件处置」** Tab 中维护。**河段或湖泊编码**：基本信息内 **下拉单选**（可检索、可清空），表单值为 `sectionCode`；选项与生态整治「河湖长制 — 河道水体」**河流/湖泊主数据**（`initialRiverChannelMasterData` / `initialLakeWaterBodyData`）同源。**所属区域**：韶山市下辖乡镇（清溪、银田、韶山乡、杨林）筛选与表单一致。编辑弹窗 **Tabs**「基本信息」「事件处置」；污染等级/预警在**基本信息**中维护。**基本信息**含 **事件图片**；**事件处置**含处置状态、负责处理人、是否自行先期处置、联系电话、责任主体、进展与措施、队伍/物资、水质恢复、事件结果、处置完成时间、**处置图片**。两类图片均：JPG/PNG/WebP/GIF，单张≤5MB，最多 12 张，`picture-card` 预览与删除，值为 Base64 data URL。
- **事件评估**：精简列表与表单（关联应急事件）；**评估附件**为上传（PDF/Word，单文件≤20MB，原型 data URL），详情与应急事件弹窗「事件评估」Tab 中展示**文件名**，并提供**查看**、**下载**链接（与 `pdfUrl` 同源）。
- **风险识别**（实现于 `riskIdentification.tsx`，由 `index.tsx` 挂载 `RiskIdentificationRouter`，状态 `riskData` 在子菜单间切换不丢失）：六个子模块均为 **Card + 筛选 + 表格 + 字段管理 + 导入/导出 + 新增/详情/编辑** 的全链路原型（演示数据）。包括：**风险源企业信息**；**应急物资**（所属社会物资点为下拉单选）；**社会物资点**（详情可查看关联应急物资）；**应急预案信息**（查阅/下载为演示 PDF 链接）；**应急队伍信息**（编辑含「基本信息」与「人员」Tab）；**应急专家库**。
- **事件复盘**（`eventReview.tsx`，侧栏「事件复盘」，状态 `eventReviews` 在侧栏切换时保留；物资数据来自 `riskData.socialPoints` + `riskData.supplies`）：基于 **应急事件** 与 **事件评估** 数据。**可选入复盘**的应急事件须已办结（原型以 **办结日期 `endDate` 有值** 判定）。**复盘编号**由系统按 **FP-年-MMDD-序号** 在保存时自动生成（新增时随复盘日期预览；编辑只读展示不改号）。列表支持区域/牵头单位/事件名称/编号/日期等拆分字段筛选、**字段管理**（列显隐，与风险识别表格工具同源）、导入导出示意、**新增/编辑/详情**。**详情**为**单页纵向排版**（弹窗内容区滚动，**无 Tab**）：自上而下为复盘登记摘要 → 结论与关键指标（含**统计人员数量**等）→ 关联应急事件 → **过程时间线**（**仅只读**；三节点：**应急事件上报**、**事件处置**、**事件评估**）→ 事件评估 → 队伍/物资/专家 → **物资类型统计**（按登记行按物资类型汇总的柱状图，无其它演示图）。复盘物资含**数量**与**单位**分列登记。**编辑**须选择关联事件（已办结）；**事件评估**随关联事件**自动匹配**（同事件多条时取**评估日期最新**的一条）；复盘日期与牵头单位、结论摘要等照常填写；**专家**来自应急专家库多选；**应急队伍多选**，下方为所选队伍人员的**统一表格**，默认勾选各队**全部人员**，可取消勾选；**物资**先选**社会物资点**，工具条控件**同一行排列**（窄屏横向滚动），**添加物资行**与批量操作同排；从该点下**应急物资**选品（类型/名称自动带出），支持勾选行后**批量填写数量**、**批量删除**。若该事件尚无评估记录则提示需先在「事件评估」登记。

- **查询规范统一**（`index.tsx` / `riskIdentification.tsx` / `eventReview.tsx`）：所有列表查询区统一为**最多两行**、**无单独筛选标题**、按钮组固定在末位（查询/重置）。原“关键词”检索已拆分为独立字段并保持原筛选语义；字段布局按“**所属区域 → 枚举下拉 → 名称类 → 编码类 → 时间类**”组织，不同台账按其业务字段映射到对应分组。
