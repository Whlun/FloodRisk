# 遥感监测

## 功能

- **入口**：一张图系统壳子路径 `yaogan`（与综合态势同级），顶栏菜单「遥感监测」。
- **布局**：左侧 **图层控制** + **数据列表**（可折叠面板）；右侧 **MapLibre 全幅影像底图**（与综合态势同源演示 Esri World Imagery），叠加演示 GeoJSON 图层。
- **图层控制**：
  - **水质污染浓度**：叶绿素 / 悬浮物单选；图例条 0–50；地图为演示填色面（正式可换 WMS/WMTS）。
  - **河湖岸线变化**：疑似问题图斑、河道变化面（勾选显隐）。
  - **地面植被覆盖**：NDVI 勾选。
  - **地物分类**：水域 / 建筑用地 / 绿地 / 农田 / 道路 / 其他（多选 + 色块图例）。
- **数据列表**：与上方 **水质指标**（叶绿素 / 悬浮物）**联动**，两套**不同**演示时间轴；**日期范围**在各自时间轴上再筛选；**播放 / 暂停**按 2s 周期间自动循环切换时间；切换时刻与指标会驱动水质填色等演示图层（占位逻辑）。

## 访问

开发预览：`/prototypes/韶山高新区水环境综合整治一张图/yaogan`

## 技术说明

- 依赖 `maplibre-gl`；底图样式复用 `../zonghe-taishi/zhtMapStylePresets` 中 `ZHT_IMAGERY_MAP_STYLE_SPEC`。
- 演示矢量数据见 `yaoganDemoGeo.ts`；对接生产时将 `setData` / 栅格 `tiles` 替换为真实服务 URL 与鉴权。
