# 第一章 引言

## 1.1 编写目的

本用户手册旨在为韶山市水环境综合整治一张图系统的使用者提供详细的操作指南。通过本手册，用户能够：

1. 快速了解系统的整体架构和功能模块
2. 掌握各业务模块的操作流程和使用方法
3. 熟悉系统的数据管理和报表功能
4. 提高日常业务工作的效率

本手册适用于韶山市高新区水环境管理相关业务人员、系统管理员及技术维护人员参考使用。

## 1.2 读者对象

本手册的预期读者包括：

| 读者类型 | 说明 |
|----------|------|
| 业务操作人员 | 日常使用系统进行水环境设施管理、巡河记录、事件处理等业务操作的工作人员 |
| 管理人员 | 查看统计数据、报表分析、决策支持的部门负责人及管理人员 |

| 运维人员 | 负责系统日常运行维护的技术支持人员 |

## 1.3 术语定义

| 术语 | 定义 |
|------|------|
| 一张图 | 将水环境相关设施、监测点位、污染源等数据整合到统一地图平台进行可视化展示和管理 |
| 河湖长制 | 由各级党政主要负责人担任"河长""湖长"，负责组织领导相应河湖的管理和保护工作的制度 |
| 排口 | 入河入海排污口的简称，指直接或者通过管道、沟、渠等排污通道向环境水体排放污水的口门 |
| 断面 | 河流监测断面，指在河流上设置的用于水质监测的特定位置 |
| 遥感监测 | 利用遥感技术对水体、岸线、植被等进行远距离监测和分析的技术手段 |
| 应急预案 | 针对可能发生的水环境污染突发事件，预先制定的应急处置方案 |

# 第二章 系统功能总体说明

## 2.1 系统概述

韶山市水环境综合整治一张图系统是基于GIS地理信息技术的综合管理平台，集成了水环境设施管理、生态整治项目管理、遥感监测分析、应急协同指挥、报表统计分析等功能模块。系统通过"一张图"的方式，实现对韶山市高新区水环境相关数据的统一管理和可视化展示，为水环境保护和治理提供信息化支撑。

### 2.1.1 系统目标

1. **数据整合**：整合泵站、管网、排口、污水厂等设施信息，形成统一的水环境基础数据库
2. **可视化展示**：通过地图直观展示各类设施分布、监测点位、水质状况等信息
3. **业务协同**：支持河湖长制日常业务、应急事件处置、项目管理等协同工作
4. **决策支持**：提供统计分析、报表导出等功能，辅助管理决策

### 2.1.2 功能架构

系统采用模块化设计，主要包含以下功能模块：

```
┌─────────────────────────────────────────────────────────────┐
│                   韶山市水环境综合整治一张图                    │
├─────────────────────────────────────────────────────────────┤
│  综合态势  │  设施管理  │  生态整治  │  遥感监测  │  应急协同  │  系统管理  │
├─────────────────────────────────────────────────────────────┤
│                        数据服务层                             │
│      设施数据  │  监测数据  │  空间数据  │  业务数据           │

│                        基础设施层                             │
│      GIS地图引擎  │  数据库  │  应用服务器                    │
└─────────────────────────────────────────────────────────────┘
```

# 第三章 功能介绍

## 3.1 综合态势

### 3.1.1 功能概述

综合态势模块是系统的核心展示页面，以"一张图"的形式集中展示韶山市水环境相关设施的分布情况、运行状态和监测数据。用户可以直观地查看各类水环境要素的空间分布和实时状态。

### 3.1.2 功能列表

| 功能项 | 说明 |
|--------|------|
| 水系分布展示 | 在地图上展示河流、湖泊等水系分布 |
| 水库分布展示 | 展示辖区内水库位置及基本信息 |
| 排口分布展示 | 展示入河排口位置及状态 |
| 管网布局展示 | 展示雨水管网、污水管网的空间布局 |
| 水质达标展示 | 展示监测断面的水质达标情况 |
| 断面溯源分析 | 分析断面污染来源 |
| 排口报警日历 | 展示排口报警的时间分布 |
| 汛期污染强度分析 | 分析汛期污染强度变化趋势 |

### 3.1.3 操作说明

#### 3.1.3.1 查看综合态势

1. 点击左侧导航"综合态势"菜单
2. 系统默认展示韶山市水环境综合态势一张图
3. 地图中央显示主要水系和设施分布
4. 左侧显示统计指标卡片
5. 右侧显示分析看板

#### 3.1.3.2 图层控制

1. 点击地图左上角图层控制工具
2. 勾选或取消勾选需要显示的图层
3. 支持的图层包括：
   - 水系图层
   - 水库图层
   - 排口图层
   - 管网图层
   - 监测点位图层
   - 视频监控点位图层

#### 3.1.3.3 查看设施详情

1. 在地图上点击设施图标（如泵站、排口等）
2. 系统弹出设施详情信息窗口
3. 详情窗口显示设施基本信息、实时监测数据等
4. 可切换查看"实时监测"、"视频监控"等标签页

#### 3.1.3.4 断面溯源分析

1. 在右侧分析看板选择"断面达标"标签
2. 选择需要分析的监测断面
3. 点击"溯源分析"按钮
4. 系统展示该断面的污染来源分析结果

#### 3.1.3.5 地图搜索

1. 点击地图工具栏"搜索"按钮
2. 输入设施名称或关键字
3. 系统返回匹配的设施列表
4. 点击搜索结果可定位到对应位置

### 3.1.4 数据说明

综合态势模块展示的数据来源于各业务模块的基础数据：

| 数据类型 | 数据来源 | 更新频率 |
|----------|----------|----------|
| 设施分布数据 | 设施管理模块 | 实时更新 |
| 监测数据 | 在线监测系统 | 实时更新 |
| 报警数据 | 监测报警系统 | 实时更新 |
| 统计数据 | 业务数据统计 | 每日更新 |

## 3.2 设施管理

### 3.2.1 功能概述

设施管理模块用于管理韶山市高新区范围内各类水环境设施的基础信息和运行数据，包括排水管网、泵站、排口、污水厂、事件管理和排水户管理等子系统。

### 3.2.2 排水管网管理

#### 3.2.2.1 排水管点管理

排水管点管理功能用于管理检查井、雨水口、交汇井、阀门井等各类排水管点的信息。

**功能操作：**

1. 点击左侧导航"设施管理" → "排水管网" → "排水管点"
2. 系统展示排水管点列表页面
3. 支持以下操作：
   - **查询**：输入管点编号、名称等条件进行筛选
   - **新增**：点击"新增"按钮，填写管点信息
   - **编辑**：选择一条记录，点击"编辑"修改信息
   - **删除**：选择一条记录，点击"删除"移除数据
   - **导出**：将查询结果导出为Excel文件
   - **地图定位**：点击"定位"按钮在地图上查看管点位置

**管点信息字段：**

| 字段名 | 说明 |
|--------|------|
| 管点编号 | 管点的唯一标识编码 |
| 管点名称 | 管点的名称 |
| 管点类型 | 检查井/雨水口/交汇井/阀门井等 |
| 所在位置 | 管点所在地址 |
| 坐标 | 管点的地理坐标 |
| 建设年代 | 管点建设年份 |
| 运行状态 | 正常/检修/故障/在建 |

#### 3.2.2.2 排水管线管理

排水管线管理功能用于管理雨水管线、污水管线等排水管网的空间信息和属性信息。

**功能操作：**

1. 点击"排水管网" → "排水管线"
2. 系统展示排水管线列表
3. 支持查询、新增、编辑、删除、导出等操作
4. 可在地图上查看管线的空间分布

**管线信息字段：**

| 字段名 | 说明 |
|--------|------|
| 管线编号 | 管线的唯一标识编码 |
| 管线名称 | 管线的名称 |
| 管线类型 | 雨水管/污水管/合流管等 |
| 管径 | 管道直径（mm） |
| 管长 | 管道长度（m） |
| 材质 | 管道材质（混凝土/钢管/PE管等） |
| 起点编号 | 起始管点编号 |
| 终点编号 | 终止管点编号 |
| 建设年代 | 建设年份 |
| 运行状态 | 正常/检修/故障/在建 |

#### 3.2.2.3 管线档案信息

管线档案信息功能用于管理管网相关的档案资料，如设计图纸、竣工资料等。

**功能操作：**

1. 点击"排水管网" → "管线档案信息"
2. 查看管网的档案资料列表
3. 支持上传、下载、预览档案文件

### 3.2.3 泵站管理

#### 3.2.3.1 泵站信息管理

泵站信息管理功能用于管理排水泵站、提升泵站等泵站设施的基础信息。

**功能操作：**

1. 点击"泵站管理" → "泵站信息"
2. 系统展示泵站信息列表
3. 点击某条记录可查看泵站详情
4. 详情页面包含多个标签页：
   - **基本信息**：泵站名称、地址、规模、建设年代等
   - **设备信息**：水泵、电机等设备信息
   - **实时监测**：当前运行状态、流量、水位等
   - **视频监控**：泵站内的视频监控画面
   - **运维记录**：日常巡检、维修保养记录

**泵站信息字段：**

| 字段名 | 说明 |
|--------|------|
| 泵站编号 | 泵站的唯一标识编码 |
| 泵站名称 | 泵站名称 |
| 泵站类型 | 排水泵站/提升泵站/雨水泵站等 |
| 所在位置 | 泵站地址 |
| 设计规模 | 设计排水能力（m³/d） |
| 装机容量 | 总装机功率（kW） |
| 水泵数量 | 配备的水泵台数 |
| 建设年代 | 建设年份 |
| 运行状态 | 正常/检修/故障/在建 |

#### 3.2.3.2 泵站统计

泵站统计功能提供泵站相关数据的统计分析功能。

**功能操作：**

1. 点击"泵站管理" → "泵站统计"
2. 系统展示泵站统计图表
3. 统计内容包括：
   - 泵站数量统计（按类型、状态分类）
   - 运行数据统计（排水量、电耗等）
   - 故障率统计
4. 支持导出统计报表

#### 3.2.3.3 安全指数评估

安全指数评估功能用于对泵站进行安全风险评估。

**功能操作：**

1. 点击"泵站管理" → "安全指数评估"
2. 系统展示各泵站的安全评估结果
3. 评估指标包括：
   - 设备安全指数
   - 运行安全指数
   - 环境安全指数
   - 综合安全指数

#### 3.2.4.3 责任主体信息

责任主体信息功能用于管理排口的责任主体信息。

**功能操作：**

3. 维护责任主体的联系方式、职责范围等信息

#### 3.2.4.4 排口核查行动小组库

排口核查行动小组库功能用于管理参与排口核查的工作小组信息。

## 3.4 遥感监测

### 3.4.1 功能概述

遥感监测模块利用卫星遥感技术，对水体水质、岸线变化、植被覆盖等进行监测分析，为大范围水环境监测提供技术支撑。

### 3.4.2 功能列表

| 功能项 | 说明 |
|--------|------|
| 水质指标监测 | 基于遥感数据反演叶绿素、悬浮物等水质指标 |
| 岸线问题监测 | 监测岸线违规占用、垃圾堆放等问题 |
| 岸线变化分析 | 分析岸线的变化趋势 |
| NDVI植被指数 | 监测水体周边植被覆盖情况 |
| 土地利用分类 | 分析区域土地利用类型分布 |

### 3.4.3 操作说明

#### 3.4.3.1 查看遥感监测数据

1. 点击左侧导航"遥感监测"菜单
2. 系统展示遥感监测主界面
3. 左侧显示图层控制面板和数据列表
4. 中央显示遥感影像底图

#### 3.4.3.2 图层控制

1. 在左侧面板选择需要显示的图层：
   - 水质指标图层
   - 岸线问题图层
   - 岸线变化图层
   - NDVI图层
   - 土地分类图层
2. 勾选或取消勾选控制图层显示

#### 3.4.3.3 水质指标查看

1. 选择"水质指标"图层
2. 选择指标类型：
   - 叶绿素浓度
   - 悬浮物浓度
3. 使用时间轴选择查看时间点
4. 可点击播放按钮查看时间序列变化

#### 3.4.3.4 岸线问题查看

1. 选择"岸线问题"图层
2. 地图上显示检测到的岸线问题点位
3. 点击问题点位查看详细信息
4. 问题类型包括：
   - 违规建筑
   - 垃圾堆放
   - 占用河道
   - 其他问题

#### 3.4.3.5 数据列表查看

1. 点击左侧数据列表标签
2. 查看遥感数据记录列表
3. 选择数据记录可在地图上定位

### 3.4.4 数据说明

| 数据类型 | 数据来源 | 更新频率 | 空间分辨率 |
|----------|----------|----------|------------|
| 水质指标 | 卫星遥感反演 | 按周期更新 | 10-30米 |
| 岸线数据 | 卫星影像解译 | 季度更新 | 2-10米 |
| NDVI数据 | 多光谱遥感 | 月度更新 | 10米 |
| 土地分类 | 遥感分类 | 年度更新 | 10米 |
